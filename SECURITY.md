# Website security

This repository serves static product pages through Next.js/Vercel. It does not
process submitted media URLs or store downloaded files. Its pages have no user
accounts or site-owned database. Keep dependencies current.

For a security issue in the download application, use the original repository's
[private reporting flow](https://github.com/Lord-shaban/OpenDownload/security/advisories/new).
Do not post exploit material, private URLs or credentials in public issues.

Website security concerns should use this repository's
[private reporting flow](https://github.com/Lord-shaban/OpenDownload-Website/security/advisories/new).
No independent security audit or
response-time guarantee is claimed. Website preview/deployment credentials,
environment files and Vercel OIDC tokens must never be committed.
